# wplid-app: Smart To-Do List

A modern, high-performance To-Do List application designed to boost your daily productivity and organize your workflow.

## ✨ Features
* **Smart Task Management:** Create, organize, and track your daily tasks effortlessly.
* **Adaptive Theming:** Flawless Light Mode and Dark Mode support for a comfortable viewing experience day or night.
* **Cross-Platform Ready:** Designed with an architecture that can easily scale across Android, PC, and Web.
* **Clean UI/UX:** Intuitive interface with smooth transitions and interactions.
* **Fast Performance:** Optimized architecture for quick loading and immediate responsiveness.

## 🛠️ Prerequisites
* [Android Studio](https://developer.android.com/studio)
* Android Emulator or a physical Android device.

## 🚀 Run Locally

1. Clone the repository:
   ```bash
   git clone [https://github.com/wplid/wplid-app.git](https://github.com/wplid/wplid-app.git)


Open Android Studio.

Select Open and choose the directory containing this project.

Allow Android Studio to fix any incompatibilities as it imports the project.

Create a file named .env in the root project directory and set GEMINI_API_KEY in that file to your API key.

Run the app on an emulator or a physical device.
